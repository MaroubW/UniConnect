🎓 Course Service - SOAP Web Service

✓ Service Active

Service Information

This is a SOAP web service for managing university courses and schedules.

WSDL URL:
http://localhost:8080/course-service/services/course?wsdl
Service Endpoint:
http://localhost:8080/course-service/services/course
Namespace:
http://service.course.soa.university.com/

Available Operations

createCourse

Create a new course in the system

getCourseById

Retrieve a course by its ID

getCourseByCode

Retrieve a course by its code

getAllCourses

Get all courses in the system

getCoursesBySemester

Get courses for a specific semester

getCoursesByProfessor

Get courses taught by a professor

updateCourse

Update an existing course

deleteCourse

Delete a course from the system

addSchedule

Add a schedule to a course

updateSchedule

Update an existing schedule

deleteSchedule

Delete a schedule

getCourseSchedules

Get all schedules for a course

searchCourses

Search courses by name or code

getAvailableCourses

Get courses with available capacity

Testing the Service

You can test this SOAP service using tools like:

  • SoapUI - Import the WSDL and test operations
  • Postman - Create SOAP requests
  • curl - Send SOAP XML requests via command line
  • Java Client - Generate client code using wsimport

Sample SOAP Request

<soapenv:Envelope xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/" 
                  xmlns:ser="http://service.course.soa.university.com/">
   <soapenv:Header/>
   <soapenv:Body>
      <ser:getAllCourses/>
   </soapenv:Body>
</soapenv:Envelope>
