Grade Service API

FastAPI service for managing student grades (MongoDB + Motor)

Overview

The Grade Service is a REST API built with FastAPI and Motor (async MongoDB driver) to manage student grades and calculate their average.

  • Create, read, update, and delete grades
  • Store grades in MongoDB
  • Compute student average based on all their grades

Technology Stack

  • Framework: FastAPI
  • Web server: Uvicorn
  • Database: MongoDB
  • Driver: Motor (AsyncIOMotorDatabase)
  • Language: Python 3.9+

Installation & Setup

1. Install dependencies

pip install fastapi uvicorn "motor" pydantic

2. MongoDB configuration

Example database.py:

from motor.motor_asyncio import AsyncIOMotorClient, AsyncIOMotorDatabase

MONGO_URL = "mongodb://localhost:27017"
DB_NAME = "grades_db"

client = AsyncIOMotorClient(MONGO_URL)

def get_database() -> AsyncIOMotorDatabase:
    return client[DB_NAME]

3. Start the server

From the project root (where main.py is located):

python -m uvicorn main:app --reload

4. API documentation (Swagger)

  • Swagger UI: http://127.0.0.1:8000/docs
  • ReDoc: http://127.0.0.1:8000/redoc

Data Models & Schemas

GradeCreate (request body)

Field Type Required Description
student_id int Yes Identifier of the student
subject str Yes Subject name (e.g. "Math")
grade_value float Yes Numeric grade value

Grade (response model)

Field Type Description
id str MongoDB ObjectId as string
student_id int Identifier of the student
subject str Subject name
grade_value float Grade value

AverageResponse

Field Type Description
student_id int Identifier of the student
average float Average grade value for the student

Endpoints

GET /grades/

Retrieve a paginated list of all grades.

List Grades

Query Parameters

NameTypeDefaultDescription
skip int 0 Number of documents to skip (for pagination)
limit int 100 Maximum number of documents to return

Response

200 OK — JSON array of Grade objects.

[
  {
    "id": "665f2a3c5b8b8e2f9f3acd12",
    "student_id": 1,
    "subject": "Math",
    "grade_value": 18.0
  }
]

GET /grades/{grade_id}

Retrieve a single grade by its ID.

Get Grade

Path Parameters

NameTypeDescription
grade_id str MongoDB ObjectId as string

Responses

  • 200 OK — Returns the Grade object.
  • 404 Not Found — If no grade exists with this ID.

POST /grades/

Create a new grade.

Create Grade

Request Body

Content-Type: application/json

{
  "student_id": 1,
  "subject": "Math",
  "grade_value": 18.0
}

Response

  • 200 OK — Returns the created Grade with generated id.

PUT /grades/{grade_id}

Update an existing grade completely.

Update Grade

Path Parameters

NameTypeDescription
grade_id str MongoDB ObjectId of the grade

Request Body

{
  "student_id": 1,
  "subject": "Math",
  "grade_value": 19.5
}

Responses

  • 200 OK — Returns the updated Grade.
  • 404 Not Found — If grade does not exist.

DELETE /grades/{grade_id}

Delete a grade by ID.

Delete Grade

Responses

  • 200 OK — {"message": "Grade deleted"}
  • 404 Not Found — If grade does not exist.

GET /grades/student/{student_id}/average

Compute the average grade for a specific student.

Student Average

Path Parameters

NameTypeDescription
student_id int Identifier of the student

Responses

  • 200 OK — Returns AverageResponse:
{
  "student_id": 1,
  "average": 17.25
}
  • 404 Not Found — If no grades are found for this student.

Example cURL Requests

Create a grade

curl -X POST "http://127.0.0.1:8000/grades/" ^
  -H "Content-Type: application/json" ^
  -d "{ \"student_id\": 1, \"subject\": \"Math\", \"grade_value\": 18 }"

Get all grades

curl "http://127.0.0.1:8000/grades/?skip=0&limit=10"

Get a student's average

curl "http://127.0.0.1:8000/grades/student/1/average"
